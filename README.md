# Around The U.S.

## Descripción

Around The U.S. es un proyecto web interactivo que simula una red social de fotografías de lugares alrededor del mundo. El usuario puede editar su perfil, agregar nuevas tarjetas con fotos de lugares, marcarlas como favoritas, eliminarlas y ver una versión ampliada de cada imagen.

## Funcionalidad

- Edición del perfil de usuario (nombre y descripción) mediante una ventana emergente.
- Generación dinámica de tarjetas a partir de una plantilla HTML (`<template>`) y un array de datos.
- Agregar nuevas tarjetas de lugares con nombre e imagen mediante un formulario.
- Marcar/desmarcar tarjetas como "me gusta".
- Eliminar tarjetas individualmente.
- Ver una versión ampliada de la imagen de cada tarjeta en una ventana emergente.

## Tecnologías

- HTML5
- CSS3 (metodología BEM)
- JavaScript (ES6+)
